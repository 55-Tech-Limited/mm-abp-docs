## 2026-10-09

### ✨ 新增

- **两套端点：`/fixtures/*` 与 `/futures/*`。** 每个带选项的端点现在都有明确前缀：
  `GET /fixtures/betslip`、`POST /fixtures/place-orders`、`GET /fixtures/orders`、
  `GET /fixtures/bets`、`GET /fixtures/markets`，以及 `/fixtures/cancel-*` 这一对——外加镜像的
  `/futures/*` 一整套。参见[概览 → 两套端点](/zh/abp-api/overview#两套端点赛事与期货)。
- **期货赔率单与盘口列表已上线。** `GET /futures/betslip?futureId=…&futureOutcomeId=…&participantId=…`
  按博彩商返回冠军盘赔率与额度，并注册与赛事端点相同的 60 秒滑动 WebSocket 订阅，其后的价格变动以
  `betslip` 增量推送。`GET /futures/markets?sportId=…` 列出已缓存的期货盘口。

### 🔁 变更

- **拆分前的路径继续可用**，作为已弃用的别名（`/betslip`、`/place-orders`、`/orders`、`/bets`、
  `/markets`、`/cancel-orders`、`/cancel-all-orders`）——相同的处理逻辑、相同的行为，且没有下线
  日期。它们在 OpenAPI 规范中标记为 `deprecated`；你可以按自己的节奏迁移到 `/fixtures/*`。
- **`requestUuid` 会被规范化。** ABP 现在会将该键改写为标准的小写带连字符形式，因此订单上回传的值
  在*拼写*上可能与你发送的不同。这修补了一个真实的漏洞：此前仅改变大小写的重试会被当作第二个不同
  的订单接受。请按规范化后的形式匹配，不要做逐字节比较。参见
  [核心概念 → 幂等性](/zh/abp-api/concepts#幂等性与请求去重)。

### ⚠️ 破坏性变更（仅涉及期货字段）

赛事端点不再接受期货标识符。以下两项变更只影响此前返回 `501 Not Implemented` 的字段，因此任何能
正常工作的调用行为都不会改变：

- `POST /fixtures/place-orders`（及其已弃用别名 `POST /place-orders`）对
  `futureId` / `futureOutcomeId` / `participantId` 返回 `422`，而不再是 `501`。
- `GET /fixtures/betslip`（及其已弃用别名 `GET /betslip`）不再声明 `futureId` 或 `participantId`；
  期货选项会返回 `400` 而不再是 `501`，并指向 `/futures/betslip`。

### 🚧 即将推出

- **期货下单以及期货订单/投注读取**——`POST /futures/place-orders`、
  `POST /futures/cancel-orders`、`POST /futures/cancel-all-orders`、`GET /futures/orders`、
  `GET /futures/bets` 与 `GET /futures/bets/{betId}` 返回 `501`。它们会**先做校验**（请求体错误返回
  `422`，过滤条件错误返回 `400`），因此今天就按这些端点做好集成，等下单功能上线时无需改动。

## 2026-06-17

### 🔁 变更

- **币种的唯一真实来源。**账户的交易币种现在仅来自 `accounts.currencyId`；已移除默认币种猜测。订单金额以 `orderCurrency`（默认 `USD`）计价，而投注与余额使用账户的原生币种。参见[币种与额度](/zh/abp-api/currency)。
- **REST 赔率单路径与 WebSocket 路径对齐**，两种传输返回相同的赔率/额度结构。

### 🔧 改进

- 扩充文档：新增[核心概念](/zh/abp-api/concepts)、[订单下注](/zh/abp-api/order-placement)（含可复制范例）、[币种与额度](/zh/abp-api/currency)、[额度与可靠性](/zh/abp-api/reliability)、[博彩商](/zh/abp-api/bookmakers)等指南，并将完整的消息/负载参考并入 [WebSocket](/zh/abp-api/websocket) 指南。

## 早期

### ✨ 新增

- **32 家博彩商集成**，统一在一套 API 之后——体育博彩、博彩交易所、预测市场与 punter 平台。参见[博彩商](/zh/abp-api/bookmakers)。
- **智能订单路由**，支持单家与多家博彩商下注、部分成交与交易所扫单模式。
- **WebSocket 可靠投递**——可选启用的至少一次投递，含 `ack` / `ack_batch` / `replay` 及 100 条消息缓冲。
- **请求去重**——按订单的 `requestUuid` 幂等，TTL 为 30 分钟。
- **分析**——`GET /positions` 与 `GET /pnl` 提供聚合敞口与盈亏。

### 🚧 即将推出

- **期货 / 冠军盘**，通过 `futureId` + `participantId`。数据模型已就位；订单下注与赔率单获取目前返回 `501 Not Implemented`。*（已被取代——赔率单与盘口列表已于 2026-10-09 上线，见上文。）*
