<Info>
ABP 在一套 API 后集成了 **32 家博彩商**。每家以其 **slug** 标识（例如 `pinnacle`、`betfair-ex`、`polymarket`）。调用 `GET /bookmakers` 获取实时列表及各博彩商的默认下注额度。你的 API key 可能被限定为一个子集——参见[鉴权](/zh/abp-api/authentication)。
</Info>

## 如何阅读本页

- **Slug**——你在创建账户、`bookmakers` 过滤与订单路由中传入的字符串。
- **类型**——体育博彩、交易所、预测市场或 punter 平台。类型会影响成交行为。
- **扫单（Sweep）**——该场所是否通过一次性扫描其订单簿来履行部分成交订单（参见[订单下注 → 交易所扫单](/zh/abp-api/order-placement)）。非扫单场所则由 ABP 的多轮加权平均逻辑成交。

## 实时赔率单拉取

多数博彩商的赔率与额度通过 [OddsPapi v5](https://docs.oddspapi.io/) 提供。少数场所（例如 `singbet`）不通过 OddsPapi 暴露额度，因此每当被订阅的价格变动时，ABP 会从博彩商 API 实时拉取——并按唯一账户去重。这对你是透明的：无论数据来源如何，`betslip` WebSocket 频道与 `GET /betslip` 的行为完全一致。

## 下注额度

每家博彩商都带有默认的 `minStake` / `maxStake`，由 `GET /bookmakers` 返回。这些是[额度级联](/zh/abp-api/currency#下注额度级联)中的*博彩商*层级——账户覆盖或更紧的赔率额度可将其取代。
